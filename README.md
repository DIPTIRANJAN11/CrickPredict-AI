# CricPredict AI 🏏

IPL Cricket Performance Analytics and Match Outcome Prediction Using Machine Learning

About the Project

CricPredict AI is a machine-learning project designed to analyze Indian Premier League (IPL) cricket data and predict match outcomes using historical match information.

Objectives

- Analyze IPL match and ball-by-ball data.
- Identify top-performing batsmen and bowlers.
- Analyze team and venue statistics.
- Train machine-learning models for match outcome prediction.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Joblib

Machine Learning Models

1. Random Forest Classifier
2. Logistic Regression
3. Decision Tree Classifier

Preliminary Results

Model| Accuracy
Random Forest| 52.46%
Logistic Regression| 51.64%
Decision Tree| 52.87%

These are preliminary results from a random train/test split. They do not establish reliable future-match prediction performance.

Project Structure

- "notebooks/" – Project notebook and analysis
- "data/" – IPL datasets
- "models/" – Saved machine-learning models
